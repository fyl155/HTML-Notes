# 标准流、浮动、Flex布局

## 1 标准流

>1.标准流也叫文档流，指的是标签在页面中默认的排布规则，例如:块元素独占一行，行内元素可以一行显示多个。


## 2 浮动
>1. 作用：让块元素水平排列。

>2. 属性名:float

>3. 属性值
```
    left:左对齐

    right:右对齐
```
```css
        /* 特点：顶对齐：具备行内块显示模式特点 */
        .one {
            width: 100px;
            height: 100px;
            background-color: brown;

            float: left;
        }
        .two {
            width: 200px;
            height: 200px;
            background-color: orange;

            /* float: left; */
            
            /* float: right; */
        }
```
