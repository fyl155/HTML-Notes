# HTML （超文本标记语言）
```html

<head>   </head>    网页的头部，存放给浏览器看的代码，如CSS
<body>   </body>    网页主体，存放给用户看的代码，如图片，文字
<title>  </title>   网页标题

```

## 5. 文本格式化标签

### 5.1 常见的文本格式 ： 加粗，倾斜，下划线，删除线；

```
标签名      效果             标签名      效果
strong     加粗               b         加粗        
em         倾斜               i         倾斜               
ins        下划线             u         下划线        
del        删除线             s         删除线    
         
```

## 6. 图像标签

###  6.1 在网页中插入图片

```html
<img src="图片的URL">
<!-- SrC用于指定图像的位置和名称是<img>的必须属性。 -->
```

## 7. 图片标签的属性

| 属性   | 作用     | 说明                       |
| ------ | -------- | -------------------------- |
| alt    | 替换文本 | 图片无法显示的时候显示文字 |
| title  | 提示文本 | 鼠标悬停在图片上面时显示   |
| width  | 图片宽度 | 值为数字，没有单位         |
| height | 图片高度 | 值为数字，没有单位         |


---
### 7.1 
```html

<img src="./cat.jpt"   alt="替换文本"   title="提示文本">                      

```

## 8. 路径
### 8.1 路径指的是查找文件时，从起点到终点经历的路线。

## 10. 多媒体标签-音频和视频标签
### 10.1 音频标签
```html
<audio src="URL"></audio>

```
```
controls      显示音频控制面板

loop          循环播放

autoplay      自动播放

```
### 10.2 视频标签
```html
<video src="URL"></video>
```

```
controls      显示音频控制面板

loop          循环播放

autoplay      自动播放

muted         静音播放


```
